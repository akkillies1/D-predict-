Alternative: script-based installation

If the unsigned Inno Setup executable is blocked, download the source-backed Windows ZIP and run the reviewed PowerShell installer from an extracted folder.

Download Windows script bundle

This avoids launching the unsigned setup EXE. It does not disable or bypass Smart App Control; Windows may still enforce script policy or block child executables.

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-dpredict.ps1 -AppVersion 2.1.6

Smart App Control

Important: the current installer is not Authenticode-signed. Windows Smart App Control may therefore block it even though the file is the verified GitHub release asset.

Do not disable Smart App Control and do not bypass a Windows security warning. A signed release requires a trusted Authenticode certificate issued to the publisher; that certificate is not currently configured for this project.

If Smart App Control blocks the installer, keep the hash above and contact the publisher for a signed build. The website cannot override Windows trust policy.

First run

  1. Run the installer as a normal Windows user.
  2. Allow the prerequisite setup to complete.
  3. When prompted for database storage, choose Local PostgreSQL and select a data folder.
  4. Wait for “Database configuration saved” before D-Predict starts.
