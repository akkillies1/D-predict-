The product

One cockpit for the research loop.

D-Predict is designed around a disciplined workflow rather than a black-box buy/sell button.

Live instrument search

Find and activate instruments quickly with live ticker suggestions and a local market workspace.

Market research

Inspect historical and current market information before forming a thesis.

Reproducible research

How it works

Discover → Research → Predict → Validate → Monitor

The workflow is intentionally sequential. A prediction is not treated as a trade simply because a model produced one.

01 · DiscoverSearch for a symbol and activate it.
02 · ResearchInspect market history and context.
03 · PredictGenerate model outputs and timing estimates.
04 · ValidateCheck temporal out-of-sample evidence and uncertainty.
05 · MonitorContinue observing the thesis instead of assuming success.
Installation

Install it like a normal Windows app.

The D-Predict Installer handles the technical setup. You should not need to live in PowerShell to use the product.

1. Download

Get the latest stable D-Predict Installer from the official release.

2. Install

Choose an installation folder and let D-Predict check the required local components.

3. Launch

Start D-Predict. The local services are brought up and the dashboard opens in your browser.

For research validation, you can optionally set up historical market data after installation. Historical-data availability and model performance are kept separate from software installation.

Built for evidence

No accuracy theatre.

D-Predict is being built around reproducible research, point-in-time data and explicit uncertainty. The system does not claim model accuracy until real historical data has been downloaded and evaluated.

Temporal evaluation

Models are compared on common purge-aware expanding out-of-sample folds.

Untouched holdout

A final temporal holdout remains outside model selection.

Execution gates

Automated live broker orders remain gated behind research validation and execution checks.
